# Portfolio — Tarah Lise Gustaina Pasteur

Portfolio web animé, responsive et prêt pour GitHub Pages.

## Publication sur GitHub Pages

1. Créer un nouveau repository GitHub, par exemple `portfolio`.
2. Importer **tous les fichiers** de ce dossier en conservant le dossier `assets`.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. GitHub Pages fournira une adresse de type `https://VOTRE-NOM.github.io/portfolio/`.

## Structure

- `index.html` — contenu du portfolio
- `styles.css` — design, responsive et animations
- `script.js` — animations au défilement, menu mobile et barre de progression
- `assets/` — images extraites du portfolio PDF
